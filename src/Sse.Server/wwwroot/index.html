SSE PoC (SCRUM-5)

Server-to-front-end delivery over Server-Sent Events. Simulated sensor source runs in the server.

Clients

  • Vanilla JS client — also the HTTP/2 / burst test page.
  • React client — run npm run dev in clients/react (proxies to this server).
  • Blazor client — optional.

Endpoints

  • GET /sse — event stream (text/event-stream).
  • POST /admin/burst?count=1000 — fire a burst.
  • GET /admin/stats — emitted / skipped / subscribers.
